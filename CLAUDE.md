# CLAUDE.md — working rules for this repo

Alex's Brain: Fumadocs study site built from 15 handbooks; later a second brain with Django.
Read DECISIONS.md (owner's decisions), PLAN.md (v2), ARCHITECTURE.md and API_CONTRACT.md before changing things.

## Project status (several sessions work in parallel)

* STATUS.md says what is done, what is in progress (and by whom) and what is open. This file is only read at
  session start and goes stale: re-read STATUS.md and `git log main --oneline -20` before starting a piece of
  work and before telling the owner what exists or is missing.
* Before you start: add your line under "In progress" (date, session/branch, task, files). In the commit that
  finishes it: move it to "Done" with the commit subject. Keep STATUS.md short; details belong in commits.
* Work in a worktree or branch only from current main, and look at main again before reporting.

## Communication and conventions

* Talk to the owner in Vietnamese. Code, comments, commit messages, file/folder names, slugs: English, ASCII.
  UI text on the site: Vietnamese (Fumadocs strings in `web/lib/i18n-vi.ts`).
* One commit per step, English message, local only. No git remote, no push, no deploy.
* Never delete originals: `archive/html/` (15 original HTML, untouched), `web/public/original/` (copies, only
  the Google Fonts `<link>` tags removed), `archive/*.zip`, `raw/` (gitignored). Never touch `_to_delete/`.
* Content fidelity: never rewrite, shorten or summarize handbook text. Structure/format changes only
  (merging items into pages, heading levels, GitBook syntax). Fix only broken markup.
* Never read whole HTML/JSON/markdown dumps into the conversation; use head/grep/scripts that print summaries.
* `backend/` is Django (phase 2). Auth lives only there; Next has no auth code. `make check` must pass before a commit.

## Server mode rules

* `output: 'standalone'`. Nothing under `content/` is bundled; `CONTENT_DIR` and `SEARCH_DB` point at disk.
  `npm run build` must stay independent of the number of pages (target < 5 min, < 4 GB RAM).
* Docs route: `dynamicParams = true`, `revalidate = false`, `generateStaticParams` returns `[]`
  (except `STATIC_EXPORT=1`, an optional tool, never the deploy target).
* `BUILD_SUBSET=slug,slug` limits loaded books in dev; the home page still lists all books.
* Theme: Space UI tokens in `app/global.css` are the source of truth (`--background`, `--primary`...); the Fumadocs
  `--color-fd-*` tokens are mapped onto them. Blue primary, red-orange `bw-red` highlight. Fonts via next/font only.
* App UI rubric: `web/DESIGN.md` (rules D1-D28); screenshots for a design pass: `node web/scripts/screens.mjs`.
* No runtime requests to external domains: no CDN, no Google Fonts, no analytics. Mermaid loads from
  `/vendor/mermaid/` (copied by `scripts/prepare-vendor.mjs`), `securityLevel: 'strict'`, only on pages with diagrams.
* Raw HTML in content goes through `rehype-safe-html`: unknown tags become text, images become placeholders
  unless they are local `/img/...`, embeds become links.
* Unknown code fence languages fall back to plain text (`fallbackLanguage: 'text'`).

## Import workflow

```
node web/scripts/import-gitbook.mjs <zip|html> --track <track> --slug <slug> --title "<title>" [--merge auto|m2|module|m1|none] [--replace]
```

Merge rules (owner decision, do not change without asking):
* **m2** (books with lesson groups, auto-detected from the module README "🔗 Bài học trong module" bold labels
  or from book-data sections): one page per lesson group inside a module; module README stays its page.
* **module** (course > module > item trees, e.g. Handbook 1–5): one page per module, split into "Phần N" at
  lesson boundaries above 12 lessons or ~120 KB; module README opens part 1.
* **m1** (no structure, e.g. F8): fold near-empty items into the previous page.
* Each item becomes `## <title> [#<item-file-id>]` with its headings shifted one level; links to merged items
  point at `<page>#<item-id>`. "Đã học xong" is per page.

After an import: set the position in `content/docs/<track>/meta.json`, add programs in
`scripts/extract-courses.mjs` and run it, `npm run assets:prepare` if attachments, `npm run search:rebuild`
is already done by the importer for that book. Check with `node web/scripts/smoke-test.mjs --book <slug>`.
